# springpr-ai-parent-framework
GenAI Frameworks integrated from and based on Spring AI.

## Components

This application is an out-of-box working test bed for the following GenAI components:

* Chat Model
* Chat Memory
* Coding Model
* Embedding Model
* RAG with ETL
* Vector Database
* MCP
* MCP Github Services
